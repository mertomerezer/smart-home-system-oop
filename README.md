 🏠 Smart Home System (Java OOP Project)

A console-based Smart Home Management System built using Java and Object-Oriented Programming (OOP) principles.

This project simulates a smart home environment where different smart devices can be added, managed, and controlled through a menu-driven system.

---

 🚀 Features

- ➕ Add smart devices dynamically
- 📋 List all registered devices
- 🔍 Search device by name
- 🔛 Turn devices ON / OFF
- 📊 View device status

---

 🧩 Supported Devices

 📺 Smart TV
- Change channel
- Control volume
- Display TV status

 💡 Smart Light
- Increase / decrease brightness
- Show current brightness level

 ❄️ Air Conditioner
- Increase / decrease temperature
- Set custom temperature
- Display current temperature

 🚪 Door Lock
- Lock / unlock door
- Display lock status



 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Inheritance
- Abstraction
- Polymorphism
- Encapsulation
- ArrayList (Collections Framework)
- Console-based UI (Scanner)
- Switch-case logic



 📚 OOP Concepts Applied

 🔹 Abstraction
`Devices` is an abstract base class for all devices.

 🔹 Inheritance
All smart devices inherit from the `Devices` class.

 🔹 Polymorphism
Devices are handled using a common `Devices` reference type.

 🔹 Encapsulation
Private fields are accessed through methods only.
